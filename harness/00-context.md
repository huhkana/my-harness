# 00. 컨텍스트 — 하네스 준비물

- 대상 도구: Claude Code (오케스트레이터 파일: CLAUDE.md)
- 추가 컨텍스트 문서: 없음

## 문서 목록과 역할

| 문서 | 역할 | 쓰임 |
|---|---|---|
| docs/prd.md | 기능·권한·상태 원본 | 정책 원본: 6장(기능), 7장(권한), 9장(MVP 결정 사항) |
| docs/design.md | 비주얼 규칙 원본 | 색상·타이포·간격·모서리·컴포넌트·Do's/Don'ts |
| docs/story-service.md | 판정 기준 | 유저스토리 5개 + 어기면 안 되는 것 2개 |
| docs/story-work.md | 작업 재료 | 산출물 5개 / 게이트 3곳 / 에이전트 경계 3곳 |

## 충돌 시 우선순위

1. story-service.md의 "어기면 안 되는 것" (최우선)
2. 기능·권한·상태 → prd.md
3. 비주얼 → design.md

## 원칙

- story-service.md(판정 기준)와 story-work.md(작업 재료)는 섞지 않는다.
- 원본 문서 4개는 하네스가 수정하지 않는다(읽기 전용).
