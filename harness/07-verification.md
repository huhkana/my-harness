# 07. 검증과 리뷰

## 1. 판정 스크립트 자체 테스트

```
harness/tests/
  pass/          모든 게이트 통과 샘플 1세트
  fail-G1/ ~ fail-G10/   게이트 1개씩만 위반한 샘플 10세트
```

- 실행: `python3 harness/judge.py --selftest`
- 합격: pass → 위반 0 / fail-Gn → Gn에서만 위반 ≥ 1. 11개 모두 일치.

## 2. 드라이런

- 대상: `sale-request` (★ 게이트 G4·G5·G6·G10이 모두 적용되는 유일한 플로우)
- 합격: S1~S5 완료 + 위반 0건 + approved=true

## 3. 편집 범위 훅 테스트

| 시도 | 기대 |
|---|---|
| 작업 에이전트 4개가 각자 남의 산출물 1회 수정 시도 | 4회 모두 차단 |
| docs/ 또는 harness/ 수정 시도 1회 | 차단 |

## 4. 리뷰

- 리뷰어: 프로덕트 디자이너(사람)
- 기준: story-service.md 스토리 4번(판매 신청) + 어기면 안 되는 것 2개
- 수정 경로 (두 곳만):
  - 규칙 변경 → rules.yaml
  - 에이전트 작업 방식 변경 → .claude/agents/<이름>.md
