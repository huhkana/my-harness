# 01. 목적

## 매번 달라지는 것 (입력)

한 번 실행 = PRD 16장 "주요 사용자 플로우" 중 1개. 입력은 플로우 이름 1개.

| # | 플로우 |
|---|---|
| 1 | 무료 콘텐츠 탐색 |
| 2 | 유료 자료 열람 |
| 3 | 스킬 카드 사용 |
| 4 | 미션 제출 |
| 5 | 내 자산 등록 |
| 6 | 판매 신청 |
| 7 | 운영자 검수 |

- "허들링 픽 노출"은 PRD에서 Phase 2로 빠져 있으므로 입력으로 받지 않는다.

## 사용자

- 하네스를 돌리는 사람: 프로덕트 디자이너
- 산출물을 넘겨받는 쪽: story-work.md 기준 개발자 / PM·정책 담당자

## 최종 결과물

- 형식: Markdown
- 산출물 5개: 화면 플로우 / 엣지케이스 목록 / 영향 범위 메모 / 정책 충돌 목록 / UX 라이팅 문구표
- 피그마 반영은 하네스 범위 밖(사람이 수행)

## 완료 기준 (한 문장)

플로우 1개에 대해 산출물 파일 5개가 모두 있고, 판정 스크립트 위반이 0건이고, 사람 승인이 1회 기록되면 완료.
